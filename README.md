# Pocket Lawyer

### Making Legal Information Easier to Understand

Pocket Lawyer is a web application I developed to help users explore legal topics, manage their documents, and find answers to questions related to their uploaded documents.

My goal is to make legal information easier to access through a simple and user-friendly platform.

## Features

- User registration and login
- Explore and search legal topics
- Upload and manage documents
- Ask questions based on uploaded documents
- Bookmark useful legal topics
- Personalized dashboard
- Admin interface for managing application content

## Tech Stack

- **Frontend:** React.js, Vite, CSS
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **Authentication:** JWT

## Getting Started

### Prerequisites

- Node.js
- npm
- MongoDB

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/Radikaa34/Pocket-Lawyer.git
cd Pocket-Lawyer
```

**2. Install dependencies**

```bash
npm install
```

**3. Configure environment variables**

Create a `.env` file with the environment variables required by the project, such as your MongoDB connection string and JWT secret.

Never upload your `.env` file or expose private credentials.

**4. Run the application**

Use the development commands configured in the project's `package.json` files to start the frontend and backend.
